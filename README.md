# 競馬予想支援アプリ

自分の競馬予想の基準(過去走内容・コース適性・展開)をシステム化し、スコアリング・ランキング表示・的中率の記録までを一貫して行えるWebアプリです。

## 開発の背景

普段から競馬予想を行う中で、「過去走内容→コース・距離適性→展開→調教・休み明け・馬体重→オッズ→パドック」という自分なりの評価基準を持っていました。この基準を頭の中だけで判断するのではなく、システムとして明文化・数値化することで、予想の精度や再現性を検証できるのではないかと考え、開発を始めました。

## 主な機能

- レース情報の登録・編集(日付・開催場・レース番号・芝ダート・距離・天気・馬場状態)
- 出走馬データの登録・編集(過去走内容・コース適性・展開の3項目でスコアリング)
- スコアに基づく自動ランキング表示
- レース結果の登録と、馬連・馬単・3連複の自動的中判定
- 的中率の集計・可視化
- 脚質タグ・メモタグによる馬の特徴の記録
- お気に入り馬の登録・管理
- レース回顧メモの記録
- JRA公式サイトの出馬表テキストを貼り付けるだけで、馬名・オッズ・脚質などを自動抽出して一括登録
- 馬データのCSV/Excelエクスポート・インポート
- 馬名・回顧メモの横断検索
- 馬ごとの戦績プロフィール(今走・前走・前々走…の時系列表示)
- ダークモード対応

## 技術スタック

- バックエンド: Python / FastAPI
- データベース: SQLite / SQLModel
- テンプレートエンジン: Jinja2
- フロントエンド: HTML / CSS(素のCSS、Jinja2のテンプレート継承で共通レイアウトを管理)

## セットアップ手順

1. リポジトリをクローンする
git clone https://github.com/kiyosou/keiba-yosou-app.git
cd keiba-yosou-app


2. 仮想環境を作成し、有効化する

python -m venv venv
venv\Scripts\activate


3. 必要なライブラリをインストールする

pip install fastapi uvicorn sqlmodel jinja2 python-multipart openpyxl


4. サーバーを起動する

uvicorn main:app --reload


5. ブラウザで以下にアクセスする

http://127.0.0.1:8000


## 今後の展望

現在、予想スコアとレース結果(的中したかどうか)のデータを蓄積しています。ある程度のデータ量が貯まった段階で、scikit-learnを用いた機械学習モデルを組み込み、「入力したスコアから馬券に絡む確率を予測する」機能を追加する予定です。既存の生成AIサービスに頼るのではなく、自分の予想データそのものから学習するモデルを構築することで、より自分の予想傾向に即した分析ツールに発展させたいと考えています。
